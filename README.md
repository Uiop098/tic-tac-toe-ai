# Tic Tac Toe: AI Edition

This is a modern Tic Tac Toe game wrapped in an Android shell, featuring a real AI opponent querying the Pollinations public API to generate smart moves, exactly as orchestrated!

## Modes:
1. **PvP Local:** Play with a friend on the same device.
2. **Easy Bot:** Plays random available moves.
3. **Real AI (API):** Sends the board state to a public LLM API to compute the best move.

## GitHub Actions Build
This repository automatically builds an Android APK on every push!
Download the latest `app-debug.apk` from the **Actions** tab.
